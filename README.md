# OWL24

OWL24 is a self-hosted monitoring and observability platform.

## Tech Stack

### Backend

- Python
- FastAPI
- SQLAlchemy
- Alembic
- PostgreSQL
- Redis
- Celery
- HTTPX

### Frontend

- Next.js
- React

### Infrastructure

- Docker
- Docker Compose
- Nginx

Under active development.
